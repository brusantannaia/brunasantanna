A dúvida nº1

Cowork ou Code?

Mesma inteligência, ambientes diferentes.

Cowork

Mexer nos seus arquivos

Organizar, gerar relatório, processar documentos. Roda numa VM isolada e segura, sem terminal. É o dia a dia.

Code

Construir e SUBIR

Sites, deploy, publicar no ar, git. Mais controle e poder, território mais dev. Quando precisa colocar algo no mundo.

A regra: mexeu em arquivo e gerou entregável → Cowork. Precisa publicar / subir um site → Code (o Cowork é sandbox, não publica direto na web). Comece no Cowork, suba pro Code quando precisar.

04

Comandos de barra

No Code você digita / e aparece uma lista de comandos que controlam a sessão. Não precisa decorar, é só digitar a barra e ver.

/compact/context/clear/plugin/help
Os que importam: /compact resume a conversa e economiza contexto · /context mostra quanto você já usou · /clear começa do zero · /plugin instala plugins · /help abre a lista toda.
Quando usar: os de barra controlam a SESSÃO. Pra criar seu próprio atalho de trabalho, isso virou Skill (Módulo 3). Dica: digita "/" e explora, é o jeito mais rápido de descobrir.
